# Shade Lab 3.8.2 — offline color studies for artists

Shade Lab is a portable browser app for building shading palettes, comparing color relationships and trying filters. Download **Shade-Lab-HTML-v3.8.2.zip**, extract it and open **Shade Lab.html**. No installation, server or account is required.

## Download and open

1. Under **Assets** below, download **Shade-Lab-HTML-v3.8.2.zip**.
2. Extract it into a folder. On Windows, right-click the ZIP and choose **Extract All**.
3. Open **Shade Lab.html** from that extracted folder in your desktop browser.

[Installation guide](https://github.com/Y1-studio/Shade-Lab/blob/main/INSTALLATION.md) covers setup, opening the file, saving and updates. **Installation Guide.html** is also included in the ZIP for offline use.

**Firefox:** screen color picking (**Pick screen**) does not work in Firefox.

## What you can do

- Edit ball regions directly and let linked highlight/shadow recipes follow your base color.
- Compare built-in studies or create reusable ball types from PNG masks and overlays.
- Use hue harmonies, hue limits, allowed color areas, line guides and comparison previews.
- Try Filter Lab blend modes with applied paint, opacity and split before/after results.
- Sample reference images, reuse color history, export PNGs and save editable JSON backups.
- Learn through illustrated Ball basics, Icon controls, Tools and Tabs sections. Exercises are optional; exit anytime with × or Escape.

## Files and saving

- **Shade-Lab-HTML-v3.8.2.zip:** ready-to-open app, installation/user/formula guides, examples, screenshots and credits.
- **Shade-Lab-Source-v3.8.2.zip:** reviewed current source, build scripts and tests for developers.
- **SHA256SUMS.txt:** checksums for both downloads.

The app keeps studies/types in the current browser on this device. Use **Save project** for an independent JSON backup before updating or changing browsers; reopen it with **Open JSON**. PNG exports are images, not editable project backups.

Desktop Chromium browsers are the verified target; screen picking depends on browser support. CMYK is approximate and Add (Glow) is experimental. Source and portable tutorial/layout/add-on checks passed (114 checks), with 155 lesson layouts checked through Brave's add-on.
