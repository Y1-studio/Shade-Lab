# Example add-on template

This folder is not in the registry, so it adds nothing to the app. Copy and rename it when implementing an authorized new feature. See `../README.md` for installation, the host API, cleanup, and test conventions.

The example mounts a small panel and saves a versioned count in its own project namespace. Clicking its button uses the normal Undo/Redo and persistence flow. Replace the example controls and IDs with the real feature; keep scripts, styles, documentation, and feature tests inside the copied folder.
