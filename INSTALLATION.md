# Shade Lab — download and setup

## Download the app

1. Open the [latest Shade Lab release](https://github.com/Y1-studio/Shade-Lab/releases/latest).
2. Under **Assets**, download **Shade-Lab-HTML-v3.8.2.zip**.
3. Extract the ZIP into a folder. On Windows, right-click it and choose **Extract All**. On macOS, double-click the ZIP. On Linux, use your archive manager's Extract option.
4. Open the extracted folder and double-click **Shade Lab.html**. Use a desktop browser such as Brave, Chrome or Edge. If it opens in a text editor, right-click the HTML file and choose **Open with** your browser.

Open the HTML file from the extracted folder. There is no installer, account, server or command-line setup. The app and included guides work offline after download.

**? Learn** opens short illustrated sections inside the app. **User Guide.html** explains the controls, and **Installation Guide.html** contains these setup instructions.

## Which download?

| File | Contents |
| --- | --- |
| Shade-Lab-HTML-v3.8.2.zip | Ready-to-open app, guides, examples, screenshots and credits. |
| Shade-Lab-Source-v3.8.2.zip | Editable source, build scripts and tests for developers. |
| SHA256SUMS.txt | Checksums for verifying the two ZIP downloads. |

## Save your work

Studies and reusable ball types stay in the current browser on this device. Click **Save project** to download an independent editable JSON backup. **Open JSON** imports it again. PNG exports contain images; keep JSON backups for further editing.

## Update

Save a JSON backup before updating, moving the app, changing browsers or clearing browser data. Extract the new release into a separate folder, open its **Shade Lab.html**, then use **Open JSON** to bring back your saved project if needed. Keep your backup files.
